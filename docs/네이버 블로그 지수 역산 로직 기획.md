# 네이버 블로그 지수 역산 로직 기획 (Daon Index v1.0) 

기존 캠페인 매칭 시스템의 한계를 극복하고, 광고주에게 객관적인 지표를 제공하기 위해 고안된 '다온 지수(Daon Index v1.0)'의 백엔드 / 아키텍처 및 산출 방식을 정의한 문서입니다.

## 1. 개요 (Overview)
- **목표:** 블로거가 특정 키워드에 대해 상위 노출(검색 랭크) 시킬 수 있는 역량을 점수화하여 광고주 및 내부 관리자에게 제공한다.
- **버전:** v1.0 (최신글 3개 추출 / 45일 정기 배치 / SNS 등록 트리거 방식)
- **핵심 가설:** "경쟁도(검색량)가 높은 키워드를 사용하여 상위 노출에 성공한 블로거일수록, 실제 캠페인 진행 시 광고주에게 더 큰 트래픽(전환율)을 유도할 수 있는 고가치 인플루언서다."

## 2. 데이터 흐름 및 수집 정책 (Data Flow & Trigger)

### A. 언제 수집하는가? (Trigger)
네이버 IP 차단 방지를 위해 실시간 또는 단기(7일 등) 무작위 수집을 금지하고 철저히 통제된 스케줄로만 수집합니다.
1. **이벤트 트리거 (Priority Queue):** 인플루언서가 '마이페이지'에서 본인의 블로그 주소(sns_url)를 신규 등록하거나 수정할 때, 즉시 백그라운드 갱신 대상으로 마킹되어 가장 먼저 지수를 분석합니다.
2. **정기 크론 스케줄 (Slow-Batch):** 갱신된 지 45일이 지난 블로거를 대상으로, 백그라운드 크론(Cron) 작업이 분당 2~3명씩 아주 느린 속도로 안전하게 순회하며 지수를 재계산합니다.

### B. 무엇을 수집하는가? (Target Data)
부하 단축과 효율성을 위해 **가장 최신 글 '3개'** 만 집중적으로 분석합니다.
1. **타겟 URL 정보 수집:** 블로거 고유 주소를 기반으로 네이버 RSS 피드를 호출하여 최신 3개의 포스트 제목을 긁어옵니다.
2. **키워드 추출:** 제목 내에서 의미 있는 핵심 2자 이상 단어를 최대 3개씩 선별합니다.
3. **검색량(Volume) 조회:** 네이버 검색광고 API (Naver Search Ad API)를 호출해 추출된 각 키워드의 지난달 검색량을 조회합니다.
4. **노출도(Rank) 파악:** 서버 봇이 해당 키워드를 네이버 검색 영역(VIEW/블로그 탭)에 실제 검색하여 해당 블로거의 포스팅이 1~30위(통상 1페이지) 내에 꽂혔는지 노출 순위를 찾아냅니다.

## 3. 지수 점수화 공식 (Scoring)

다음 수식에 대입하여 최종 '다온 점수'를 산출합니다.

$$Score = \sum_{i=1}^{3} \left( \frac{\text{Keyword Search Volume}_i}{\text{Rank}_i} \right)$$  
*(※ 노출 순위(Rank)가 1에 가까울수록, 키워드 자체의 검색량(Volume)이 클수록 점수가 기하급수적으로 높아지는 구조입니다. 노출되지 않은 키워드는 0점 처리합니다.)*

## 4. 기술적 아키텍처 (Architecture)

| 단계 | 수행 작업 | 활용 기술/도구 |
| :--- | :--- | :--- |
| **Collector** | 블로그 최신글 제목(3건) 수집 | `daon-index.ts` 내 Cheerio + Naver RSS |
| **Analyzer** | 키워드별 월간 검색량 데이터 수집 | **네이버 검색광고 공식 API** |
| **Ranker** | 키워드로 검색 시 블로거 노출 순위 확인 | Axios + Cheerio (v2에서 Playwright로 고도화 예정) |
| **Job Queue** | IP 차단 방지를 위한 배치 딜레이 | Next.js API Routes (Cron) + `setTimeout` |
| **Database** | 산출된 지수를 사용자 프로필에 저장 | **Supabase** `influencer_stats` 내 `daon_index` |

## 5. 남은 과제 / 주의사항 (Phase 3+)
1. **API Key 세팅 필수:** 실제 정확한 검색량을 도출하기 위해 프로덕션 서버 환경변수에 네이버 검색광고 API 키 정보(`NAVER_AD_CLIENT_ID`, `SECRET`, `CUSTOMER_ID`) 입력이 필요합니다.
2. **Ranker 고도화:** 현재는 가벼운 Cheerio 크롤링을 사용 중이나, 트래픽 증가 또는 네이버의 안티봇 정책이 강화될 경우 Headless 브라우저(Puppeteer/Playwright) 및 프록시 망 도입을 고려해야 합니다.
