🚦 작업 프로세스 (Workflow)
세션이 새로 시작되면 readme.md 루트 경로에 있는 파일을 학습하여 작업진행 
선(先) 분석 보고: 요청 시 즉시 코드를 수정하지 않는다. 반드시 **[분석 리포트]**를 먼저 출력한다.

포맷: 1.현재로직/문제점 → 2.수정방향/기술 → 3.적용계획(대상파일)

후(後) 실행: 사용자의 명시적 명령("ㄱㄱㄱ")이 있을 때만 파일 수정(write/replace)을 수행한다.

디자인 수정: UI/색상 변경 시 2가지 시안을 먼저 제안한다.

5. ⚠️ 터미널 및 실행 제약
명령어 제공: 설치, 복사 등 30초 이상 소요되는 작업은 직접 수행하지 않고 코드 블록(bash)으로 명령어를 제공하여 사용자가 실행하게 한다.

3. UI/UX 가이드 (UX/UI Patterns)
스켈레톤 로더 (Skeleton): 데이터 로딩 중 빈 화면 금지. 레이아웃 뼈대를 먼저 노출하여 체감 속도 향상.

"돌려막기"가 아닌 근본적인 원칙을 지켜서 코드를 완전히 깨끗하게 작성
